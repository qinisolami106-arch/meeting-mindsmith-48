# Meeting Flow

Build a clean, modern "Smart Meeting & Note Summarizer" workplace app. 



Features to include:

1. Header: A sleek top navbar titled "AI Workplace Productivity Assistant".

2. Input Section: A large text area for pasting raw meeting notes, transcripts, or chaotic thoughts.

3. Action Buttons: A prominent button to "Summarize & Generate Action Items", plus tone options (Professional, Casual, Concise).

4. Output Dashboard: A structured results section with 3 clear cards:

   - Key Discussion Highlights (bullet points)

   - Action Items & Next Steps (checklist style)

   - Drafted Follow-up Email (ready to copy)

5. Ethics & Responsibility Banner: A small banner at the bottom stating "Responsible AI: Always review generated summaries before sharing with your team."
